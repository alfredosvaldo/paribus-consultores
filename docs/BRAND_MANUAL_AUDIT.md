# Paribus brand manual audit

Reference reviewed: `Paribus Brand Manual.html`, supplied by the project owner on 31 August 2026. The manual was treated as a visual identity reference; its example copy and biographical claims were not treated as verified public content.

## Implemented

- Replaced the improvised uppercase text mark with the principal lowercase `paribus consultores` lockup.
- Updated the analytical square seal to the seven-point geometry supplied by the project owner, while retaining the established monochrome Paribus colour applications and compact lockup proportions.
- Replaced the prohibited boxed `P` favicon with the analytical seal on Espresso.
- Updated the generated OpenGraph image to use the negative lockup and the institutional sans-serif hierarchy.
- Changed the hero headline from Instrument Serif to Manrope 600. Instrument Serif is now reserved for the single editorial positioning statement.
- Restored Jorge Valverde to the primary navigation, keeping the header within the manual's five-item maximum.

## Already aligned

- Espresso, Bone, Paper, Graphite, and Copper match the manual palette.
- The architectural hero photography, neutral surfaces, square geometry, restrained interaction, and absence of shadows/cards align with the stated visual system.
- The content hierarchy remains concise and consulting-led rather than decorative or fashion-editorial.

## Deliberately not imported

The manual contains illustrative profile, institutional, service, publication, and contact content. None of those claims were added to the public site because the existing verified-content policy remains authoritative. The founder copy and portrait approval state are unchanged by this audit.

`BRAND.md`, `CONTENT.md`, and `DESIGN_SYSTEM.md` remain preserved unchanged as requested. This audit records the later, explicitly supplied identity reference and the resulting implementation decisions.
